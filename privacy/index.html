Privacy policy

Summary

Effective October 11, 2026.

The short version: there are no accounts, no ads and no tracking. The game only keeps a name you type and your lines, and only for class games.

What the game collects

  • Solo play: nothing is sent anywhere. Your best scores are saved in your own browser.
  • Joining a class: the class code, the name you type (up to 16 characters), the line you lock in each round, and the time you joined. The game also creates a random anonymous ID so it can tell players apart. It is not linked to your name, email or any account.
  • Launching a class: the class settings (difficulty, number of rounds) and a random anonymous ID for the teacher's browser.

The game does not ask for email addresses, passwords, ages, photos, locations or contact details. Please use a first name or nickname, never a full name or anything private. Your name is shown to your teacher and to the other people in your class on the scoreboard, and your teacher can download scores as a spreadsheet.

What is stored in your browser

The game saves a few things on your device: best scores, the class you are currently in (so Rejoin works), a teacher's most recent class code, and the anonymous sign-in. You can clear these any time by clearing this site's data in your browser settings.

Services that help run the game

  • Google Firebase stores class data and the anonymous sign-in. See Google's privacy policy.
  • Google Fonts supplies the game's fonts, so your browser contacts Google when the page loads.
  • GitHub Pages hosts the site. See GitHub's privacy statement.
  • Cloudflare handles the fittheline.com address and passes traffic to the site. See Cloudflare's privacy policy.

These providers can see technical information such as your IP address when your browser connects, as part of how the internet works. I do not sell your information, share it for advertising, or use analytics or advertising cookies.

How long class data is kept

When a teacher presses End class, the class and every player's name and lines are deleted. A class that is not ended is also set to expire about a day after it was created and is then removed automatically, which can take a little longer. Solo data never leaves your device.

Students and schools

This game is meant to be used in classrooms, including by students under 18. It collects only the name a student types. Teachers are responsible for following their school's and district's rules about students using online tools. If a student's personal information ended up in the game by mistake, email me and I will delete it.

Security

Connections to the site are encrypted. Only the browser that created a class can change or delete it, and students can only add their own line for the current round. No online service is perfectly secure, which is another reason to keep names simple.

Changes and contact

If this policy changes, the new version will be posted here with a new date. Contact: info@fittheline.com.
